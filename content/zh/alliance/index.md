# 东北高校游戏开发社团联盟

> **破土而出，回响世界。**
> From frozen ground, echoes to the world.

东北高校游戏开发社团联盟由冻土回声（Permafrost Echo）发起，连接东北三省高校游戏开发社团，通过 Game Jam、工作坊、展会等活动促进区域内开发者合作，搭建高校与产业的桥梁。

## 联盟概览

| 指标 | 数据 |
|------|------|
| 联盟社团 | 16 个 |
| 覆盖省份 | 3 个（辽宁、吉林、黑龙江） |
| 联动城市 | 6 个（沈阳、大连、阜新、长春、吉林市、哈尔滨） |
| 参与高校 | 20+ 所 |
