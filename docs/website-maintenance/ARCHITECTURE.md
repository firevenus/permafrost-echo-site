# 网站维护架构

## 目标

网站保持现有 Next.js 页面和视觉体系，同时把高频变化的事实与多语言文案分开，减少重复编辑、状态错误和 AI 上下文消耗。

## 数据流

```text
权威事实目录 ──┐
               ├─ 数据适配器 ─ 页面组件 ─ 本地预览/生产构建
多语言文案 ────┘
```

### 权威数据源

| 内容 | 权威文件 | 负责字段 |
|---|---|---|
| 活动事实 | `src/lib/data/activity-catalog.ts` | 日期、状态、排序、图片、重点活动 |
| 活动文案 | `src/lib/data/activities.ts` | 标题、地点、简介、多语言表达 |
| 合作伙伴事实 | `src/lib/data/partner-catalog.ts` | Logo、链接、反色方式、待补状态 |
| 合作伙伴文案 | `src/lib/data/partners.ts` | 名称、类别、简介、多语言表达 |
| 数字指标 | `src/lib/data/stats.ts` | 成员、高校、伙伴、地区从业者等 |
| 品牌 | `src/lib/brand.ts` | 名称、定位、Slogan |
| 文章 | `content/<locale>/articles/` | Markdown 正文和元数据 |

`src/lib/articles-data.ts` 由构建脚本生成，不是人工编辑源。

## 活动状态

- 有准确结束日期：按 Asia/Shanghai 日期自动判断；结束日期当天仍为即将/进行中，次日转为已结束。
- 只有月份或历史日程不完整：使用 `statusFallback`，不得臆造具体日期。
- 卡片显示字符串与排序日期分离，避免用展示文案排序。

## 兼容层

现有多语言数组仍含少量旧的日期、图片字段，用于降低本轮候选版迁移风险；运行时一律由权威目录覆盖。后续可在单独、已批准的架构任务中删除这些冗余字段。新增内容不得继续复制非语言字段。

## 变更边界

普通内容更新只改权威目录、对应语言文案和素材。目录结构、路由、框架、构建、依赖、全局样式或数据模型属于架构修改，必须遵循 `AGENTS.md` 的二次确认。
