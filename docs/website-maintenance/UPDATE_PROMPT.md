# 网站增量更新 Prompt

```text
请维护「冻土回声」官网。先完整阅读仓库根目录 AGENTS.md、CONTRIBUTING.md 与 docs/website-maintenance/，并遵守其中的确认、数据源和发布规则。

本次资料：
【粘贴活动、文章、合作伙伴、统计数字、图片路径及展示限制】

工作要求：
1. 先判断本次是否只涉及网站元素/内容，还是涉及网站架构。
2. 如果涉及数据模型、目录、路由、共享组件、依赖、构建、部署或全局策略，必须先提交方案并取得第一次确认；在实际修改前再次列出最终范围并取得第二次确认。未取得双重确认时，只能修改网站元素及内容。
3. 按 ARCHITECTURE.md 指定的权威数据源更新，不能在页面中重复硬编码事实。
4. 核对日期、状态、图片归属、多语言、品牌名和全站数字；不能确认的事实列入待补，不得猜测。
5. 延续现有深色、冰蓝、冻土和极光视觉体系，不改变原始 Logo 图案。
6. 运行 npm run validate:content、npm test 和 npm run build；涉及界面时检查桌面端与移动端。
7. 更新本地预览、与候选上线效果一致的单文件 HTML、修改记录和待补资料清单。
8. 不提交、不推送、不部署。发布必须另外执行 AGENTS.md 规定的双重确认。

请在结果中列出：修改文件、数据来源、检查结果、仍待人工确认事项，以及是否涉及架构。
```
